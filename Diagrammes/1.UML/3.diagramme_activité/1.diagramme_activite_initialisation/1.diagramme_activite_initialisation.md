# Diagramme d'Activité — Phase 1 : Initialisation de l'ESP32

```mermaid
graph TD
    %% Style
    classDef phase fill:#e1f5fe,stroke:#0288d1,stroke-width:2px
    classDef action fill:#fff3e0,stroke:#f57c00
    classDef decision fill:#f3e5f5,stroke:#7b1fa2
    classDef mode fill:#e8f5e9,stroke:#2e7d32

    %% Début
    Debut((ESP32 sous tension))

    %% Étape 1 : Initialisation matérielle
    Init[Initialisation materielle<br/>et logicielle]
    InitGPIO[Configurer les broches GPIO<br/>GPIO26 OUT - Pompe<br/>GPIO27 OUT - Ventilation<br/>GPIO25 OUT - Eclairage]
    InitADC[Configer les ADC<br/>GPIO34 - YL-69<br/>GPIO35 - SEN0159<br/>GPIO32 - Niveau eau]
    InitI2C[Configurer I2C<br/>GPIO21 SDA - BH1750<br/>GPIO22 SCL - BH1750]
    InitDHT[Configurer DHT22<br/>GPIO4 Digital IN]
    InitTimers[Configurer les timers<br/>Timer auto : 5 min<br/>Timer capteurs : 10s]

    Debut --> Init
    Init --> InitGPIO
    InitGPIO --> InitADC
    InitADC --> InitI2C
    InitI2C --> InitDHT
    InitDHT --> InitTimers

    %% Étape 2 : Connexion réseau
    InitTimers --> WiFi{Tenter connexion<br/>Wi-Fi}

    %% Branchement Wi-Fi
    WiFi -->|Echec| ModeDegrade1[Mode Degrade Local<br/>Auto sans serveur]
    WiFi -->|Succes| MQTT{Tenter connexion<br/>broker MQTT}

    %% Branchement MQTT
    MQTT -->|Echec| ModeDegrade2[Mode Degrade Local<br/>Auto sans serveur]
    MQTT -->|Succes| ModeNormal[Mode Normal<br/>Connecte au cloud]

    %% Modes atteints
    ModeDegrade1 --> FinInit((Initialisation terminee<br/>en mode Degrade))
    ModeDegrade2 --> FinInit
    ModeNormal --> FinInitCloud((Initialisation terminee<br/>en mode Normal))
```

### Légende des modes

| Mode | Connexion | Comportement |
|------|-----------|--------------|
| **Normal** | Wi-Fi ✅ + MQTT ✅ | L'ESP32 communique avec le backend, reçoit les commandes, publie les mesures |
| **Dégradé Local** | Wi-Fi ❌ ou MQTT ❌ | L'ESP32 exécute seul l'automatisation avec les seuils par défaut, tente de se reconnecter à chaque cycle |

### Flux alternatifs possibles

1. **Échec matériel** : Si un capteur critique (ex: DHT22) ne répond pas à l'initialisation, l'ESP32 peut soit :
   - Ignorer le capteur et continuer (mode dégradé partiel)
   - Ou bloquer le démarrage (selon la configuration firmware)
2. **Reconnexion** : Si le mode Dégradé est actif, l'ESP32 tente une reconnexion à chaque cycle de la boucle d'automatisation
